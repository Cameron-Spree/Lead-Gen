Setup checklist

What needs to exist before this becomes the real system.

  1. Create a Google Cloud project.
  2. Enable Maps JavaScript API and Places API.
  3. Create an API key and restrict it to localhost while testing.
  4. Add billing limits and daily quota alerts.
  5. Store final leads in Sheets/Airtable, not only local browser storage.
  6. Use opt-out and suppression tracking before sending cold outreach.
